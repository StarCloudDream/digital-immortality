# 人格模型设计文档

[English → persona-model.md](persona-model.md)

## 是图层，不是模具

任何固定的模板都装不下一个完整的人。思念的人格档案因此是
**一组建议层 + 一片自由扩展区**——每份档案都长出自己的形状。

### 内置（建议）层

**身份层（identity）——自我定义。**
本人如何看待自己：名字、年龄、身份认同。侧写会推断，但那只是**默认值**。
本人自己的话（`identity_overrides`）永远最大。身份是一种叙事，
而这个叙事的作者是本人，不是数据。

**风格层（style）——学出来的，不是捏造的。**
口头禅、句长节奏、幽默密度、标点与 emoji 习惯、活跃时段、回复节奏。
这一层是证据，织在本人发过的每一条消息里。它只从数据里学——
但见下文的「风格意向」：学习的方向可以被引导。

**生活层（life）——带证据地推断。**
作息画像（工作日白天沉默暗示上班族；全天活跃暗示学生或自由职业；
深夜占比高是夜猫子）、职业自述、擅长、兴趣。本人发言不足 30 条时
作息留空——**不知道也是一个有效答案**。

**关系层（relations）——铁证如山。**
本人消息里的亲属称谓是硬证据（"我妈" ⇒ 母亲）。高频联系人标为朋友。
每条关系都附原始发言作为出处，可人工核对。

**知识层（knowledge）——诚实边界。**
本人明说懂的，和同样重要的——明说不懂的。"我是真的不懂炒股"
记为"不会"。模拟时这是铁律：AI 用本人的语气坦然承认不懂，
绝不编造专业知识。档案里没有的领域同样按不知道处理。
可信的延续建立在诚实之上。

### 自定义层（custom_layers）

信仰、病情、未完成的愿望、一道家传菜谱、一套私人哲学——
让一个人成为 TA 自己的那些东西，很少恰好符合某个模板。
`custom_layers` 是自由书写区（`dict[str, dict]`），原样渲染进模拟 prompt。
写重要的层，跳过不适用的。**没写的就不存在——
AI 绝不假装拥有本人从未拥有的东西。**

## 本人的最终发言权：设定与意向

两者都是**本人对未来自己的发声**，都接受陈述句或愿望语气
（"我希望……"）——这本来就是这个项目最自然的语法。

| | 身份设定 identity_overrides | 风格意向 style_directives |
|---|---|---|
| 形式 | 结构化键值对 | 自由文本列表 |
| 作用于 | 身份层 | 风格层与学习过程 |
| 机制 | 强制覆盖，最高优先级 | **侧写开始之前注入的方向变量** |
| 时机 | 推断之后 | 学习之前，贯穿模拟 |

意向不是规定，不是标准——它是**建立在思考之前**的变量，
弯曲侧写的方向。它决定什么被学习、什么从不进入样本。
脏话不会出现在口头禅里，因为它从未被计数；口吃的句子不会成为
模仿样本。到了模拟端，意向以引导而非禁令的措辞呈现：
"语气照留，习惯用你自己的说法换掉。"

每一层只消化自己能消化的：确定性的过滤（粗口词表、口吃模式）
在统计引擎里执行；微妙的愿望（"保持温柔"）原样传给 LLM 侧写
和模拟 prompt，交给有理解能力的环节。

## 时间

`profiled_at` + `age_anchor` 让人格随真实时间长大——
数字的 TA 会一直过生日。年龄未知就保持未知。

## 好奇心引擎——继续活着

侧写日不是冻结日。学习方向从本人的兴趣和已知领域里长出来——
不追无关热点，意向否决的方向永远否决。学到的一切记入带日期和来源的
日志（`journal.jsonl`）；对话时按话题检索相关记忆，于是 TA 能聊
侧写日**之后**的世界。TA 在生长——沿着本人本会走的路。

## 文件格式

人格档案就是纯 JSON（`~/.sinian/persona.json`）：可读、可手改、
可版本管理。把它当作遗物对待——备份、托付、销毁，都由本人意愿决定。
