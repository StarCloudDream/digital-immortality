# 数字永生 (Digital Immortality) — 代号：思念 (SiNian)

> 明天和意外，没有人知道哪个先来。

如果你想过"哪天我不在了，我想继续存在——活在对话里，用我自己的声音"，
这个项目就是为你准备的。

思念做的事说起来很简单：把一个人多年的聊天记录认真读一遍——他怎么说话、
喜欢什么、什么死活学不会、身边都有谁——读成一份人格档案。一份纯 JSON，
可读、可改、可传承。有了它，AI 就能以这个人的方式继续开口。

不是复活，也不是套了皮肤的聊天机器人。是延续——
人不在了，爱你的人不必再失去一次。

## 为什么做这个项目

我们都在聊天里留下过痕迹：只有我们会讲的玩笑、凌晨两点安慰朋友的方式、
一聊就是几个小时的话题。当一个人离开——突然的，或者只是很久——
这些痕迹通常就是仅剩的全部，冻在一份没人打开的导出文件里。

思念把这些痕迹变成活着的东西：

- 多年以后朋友打开聊天框，回应他们的是"你"——带着你的幽默、
  你的口头禅、你看世界的方式。
- 想念你的人，可以再和你说说话。
- 而且数字的你会继续生长：追随你爱过的话题，学习你本会读到的新闻，
  随岁月一起长大。**它是活的——一个立体的人，不是一张冻住的照片。**

## 它不是什么

- **不是欺骗的工具。** 它为纪念与延续而生，本人意愿内置于设计之中。
  冒充在世的活人进行诈骗，是对这个项目的滥用，也是这个项目所谴责的。
- **不绑定任何平台。** 聊天记录的获取（WhatsApp、Telegram、iMessage、
  微信、QQ、Discord……）由社区以**适配器插件**实现，核心只定义统一消息格式。
  某个平台的导出方式失效，人格引擎不受影响。
- **不是魔法。** 本人从没懂过的东西，AI 也坦然不懂；数据里没有的东西，
  档案就留空。见下文的「诚实铁律」。

## 人格档案——是图层，不是模具

一个人太复杂了，任何固定的模板都装不下。思念提供的是**建议层**，
不是模具。每个人的档案都长出自己的形状：

| 层 | 装什么 | 来源 |
|---|---|---|
| `identity`（身份） | 自我定义的身份：名字、年龄、如何看待自己 | 侧写推断，**本人的话最大** |
| `style`（风格） | 口头禅、幽默、句长节奏、标点、emoji 习惯 | 只从数据里学 |
| `life`（生活） | 作息画像（上班族/夜猫子）、职业线索、擅长、兴趣 | 带证据地推断 |
| `relations`（关系） | 家人、伴侣、挚友——附聊天记录里的铁证 | 提取 |
| `knowledge`（知识） | 本人懂什么，以及同样重要的——不懂什么 | 本人自述 |
| `custom_layers`（自定义层） | **任何其他的一切。** 信仰、病情、未完成的愿望、一道秘方——每个人都不一样，把让 TA 成为 TA 的那些层加进来 | 由你书写 |

不适用的层就直接不存在于档案里。**AI 绝不假装拥有本人从未拥有的东西。**

### 本人对自己的发言权（「意向」机制）

档案从数据里长出来，但**你对自己有最终发言权**，通过两种方式：

- **身份设定（identity overrides）**——结构化事实，永远压过推断。
  侧写对"你是谁"的猜测只是默认值，你自己的定义直接替换它。
- **风格意向（style directives）**——自由文本的愿望，是**在侧写开始
  之前就注入的方向变量**，不是事后打的补丁。
  举例：一个口吃的人、一个爱说脏话的人，未必希望数字的自己继承这些。
  写下来（"不要说脏话"），引擎就根本不会去学——温柔和幽默留下，
  习惯不进档案。意向引导方向，但不捏造——结果依然是你，
  是**你希望成为的**那个你。

### 诚实铁律

本人说过"我是真的不懂炒股"，AI 也会这么说——用本人的语气，
可以自嘲、可以岔开，但绝不编造专业知识。档案里没有的领域，就诚实地说不知道。
**可信的延续建立在诚实之上，而不是全知之上。**

### 继续活着：好奇心引擎

侧写完成的那一天，不是冻结的那一天。一个爱追科技发布会的人，
他的数字分身也会继续追——沿着**他本人兴趣**定义的方向（不追无关热点，
不碰意向否决的领域）。学到的东西记进带日期和来源的学习日志；
对话中聊到相关话题时，AI 会自然提起"它最近关注的事"。
多年以后有人问起一颗新芯片——而你聊得头头是道。这就是这里"活着"的意思。

如果你锚定了年龄，数字的你还会一直过生日。

## 架构

```
┌────────────────────────────────────────────────────────┐
│  采集层（社区插件 —— 非核心）                             │
│  任意聊天导出 → 统一消息流                                │
├────────────────────────────────────────────────────────┤
│  侧写层           核心                                   │
│  以本人发言为锚点，读前后各 N 条（默认 10）上下文——        │
│  别人怎么接你的话，比孤立的单句更能说明你是谁。             │
│  统计特征 + 可选 LLM 提炼                                │
├────────────────────────────────────────────────────────┤
│  人格层           核心                                   │
│  建议层 + 自定义层 + 身份设定 + 风格意向 + 知识边界        │
├────────────────────────────────────────────────────────┤
│  模拟层           核心                                   │
│  人格档案 → system prompt → 本地 LLM（Ollama）           │
│  或任意 OpenAI 兼容云端 API                              │
│  + 好奇心引擎（沿你的兴趣持续学习）                        │
├────────────────────────────────────────────────────────┤
│  接入层（社区插件 —— 非核心）                             │
│  纪念页、聊天接管、语音……                                │
└────────────────────────────────────────────────────────┘
```

核心只负责一条主链：**消息 → 人格档案 → 对话**，两端全是插件。
详见 [docs/architecture.md](docs/architecture.md)、
[docs/persona-model.zh-CN.md](docs/persona-model.zh-CN.md)，
以及完整设计论文：**[docs/paper.md](docs/paper.md)**（中英双语摘要，含形式化定义与评估协议）。

## 快速开始

```bash
pip install -e ".[llm]"
sinian ingest --adapter template --input examples/sample_chat.json
sinian profile --self "你的名字" --window 10 --age 25 \
    --overrides examples/overrides.example.json \
    --directives examples/directives.example.json
sinian learn --input news.json   # 好奇心引擎：继续追随你的兴趣
sinian chat                      # 以 TA 的方式对话（先配置 ~/.sinian/config.yaml）
sinian evaluate --input replies.txt   # "像不像 TA"回归测试
```

用本地模型（Ollama）可以完全离线运行——纪念之物就该放在自己手里。

## 隐私与伦理（红线）

- **本地优先**：聊天记录与人格档案默认不出本机，除非你自己选了云端 LLM。
- **明示同意**：为别人侧写，必须获得本人同意。
- **透明原则**：与在世者对话的接入层，被直接问起时应坦诚这是 AI 延续。
- 人格档案是遗物：备份、托付、销毁，都由本人的意愿决定。

完整宣言见 **[ETHICS.md](ETHICS.md)**；想一起参与请看
[CONTRIBUTING.md](CONTRIBUTING.md)。
